# Agregar Imágenes a Documentos HTML

## Concepto Clave
- **Etiqueta IMG**: Se utiliza para insertar imágenes en una página web. No se insertan imágenes directamente; en su lugar, se utiliza esta etiqueta para vincular a los archivos de imagen.

## Atributos Importantes
1. **src**: Especifica la fuente de la imagen (el archivo de imagen).
2. **width** y **height**: Definen las dimensiones de la imagen.
3. **alt**: Proporciona una descripción de la imagen, mejorando la accesibilidad.

## Ejemplo
Supongamos que tienes dos archivos de imagen: `falafel.jpeg` y `salad.jpeg`. Aquí te muestro cómo se vería el código HTML para agregar estas imágenes:

```html
<img src="falafel.jpeg" width="240" height="135" alt="A falafel">
<img src="salad.jpeg" width="240" height="135" alt="A pasta salad">
```

Explicación del Ejemplo

* src: Indica el nombre del archivo de imagen.

* width y height: Ajustan el tamaño de la imagen a 240 píxeles de ancho y 135 píxeles de alto.

* alt: Proporciona una descripción que será leída por tecnologías de asistencia, como lectores de pantalla.
