# Accesibilidad Web

## ¿Qué es la accesibilidad web?
La accesibilidad web se refiere a la práctica de diseñar y desarrollar sitios web que sean utilizables por todas las personas, incluidas aquellas con discapacidades. Esto significa que cualquier persona, independientemente de sus habilidades físicas o mentales, debería poder acceder y navegar por el contenido de un sitio web.

## Ejemplos de accesibilidad web:

1. **Uso de etiquetas HTML adecuadas**:
   - **Ejemplo**: Si tienes un texto que quieres que sea un encabezado, debes usar la etiqueta `<h1>` para el título principal, `<h2>` para subtítulos, etc. Esto ayuda a los lectores de pantalla a entender la estructura del contenido.
   - **Sin accesibilidad**: Si simplemente usas texto normal sin etiquetas, un lector de pantalla no podrá identificar que es un encabezado, lo que dificulta la navegación.

2. **Subtítulos en videos**:
   - **Ejemplo**: Si tienes un video en tu sitio web, incluir subtítulos permite que las personas con discapacidades auditivas comprendan el contenido. También ayuda a aquellos que no hablan el idioma del video.
   - **Sin accesibilidad**: Un video sin subtítulos no será accesible para personas con problemas de audición, lo que limita su capacidad para entender el mensaje.

## Importancia de la accesibilidad web:
- **Inclusión**: Permite que todos, independientemente de sus habilidades, puedan acceder a la información.
- **Cumplimiento legal**: En muchos lugares, la accesibilidad web es un requisito legal, especialmente para sitios del sector público.
