# Resumen de Etiquetas HTML

## Encabezados
Los encabezados permiten mostrar títulos y subtítulos en una página web:
```html
<body>
  <h1>Encabezado 1</h1>
  <h2>Encabezado 2</h2>
  <h3>Encabezado 3</h3>
  <h4>Encabezado 4</h4>
  <h5>Encabezado 5</h5>
  <h6>Encabezado 6</h6>
</body>
```
## Párrafos

Los párrafos contienen texto:

```html
<p>Este párrafo contiene mucho texto.</p>
```

## Saltos de Línea

Los saltos de línea se especifican con la etiqueta <br>:
```html
<p>Este párrafo<br>contiene saltos de línea.</p>
```

## Texto Enfático y Negrita

Negrita: Se utiliza para llamar la atención:

```html
<p>Los colores primarios son <b>rojo</b>, <b>amarillo</b> y <b>azul</b>.</p>
```
Énfasis: Se utiliza para enfatizar texto:

```html
<p>Despierta <em>ahora</em>!</p>
```
## Listas

Existen dos tipos de listas:

* No ordenadas:

```html
<ul>
  <li>Té</li>
  <li>Azúcar</li>
  <li>Leche</li>
</ul>
```

* Ordenadas:

```html
<ol>
  <li>Rocky</li>
  <li>Rocky II</li>
  <li>Rocky III</li>
</ol>
```

## Divisiones

La etiqueta <div> define una división de contenido:

```html
<div>
  <p>Este es un párrafo dentro de un div.</p>
</div>
```
