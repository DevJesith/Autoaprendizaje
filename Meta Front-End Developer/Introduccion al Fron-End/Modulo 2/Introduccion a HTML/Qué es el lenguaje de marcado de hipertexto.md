# Conceptos Clave de HTML

1. Elementos y Etiquetas:

* Un elemento HTML está compuesto por una etiqueta de apertura y una etiqueta de cierre.

* La etiqueta de apertura indica el inicio del elemento, mientras que la etiqueta de cierre indica su final.
```html
<p>Este es un párrafo.</p>
```
Aquí, <p> es la etiqueta de apertura y </p> es la etiqueta de cierre. El texto "Este es un párrafo." es el contenido del elemento.

2. Elementos Vacíos o Autocerrados:

Algunos elementos no necesitan una etiqueta de cierre. Se les llama elementos vacíos o autocerrados.
```html
<br>
```
La etiqueta <br> se utiliza para insertar un salto de línea y no requiere una etiqueta de cierre.

3. Anidación de Elementos:

Puedes incluir un elemento dentro de otro. Por ejemplo, puedes poner un elemento de texto en cursiva dentro de un párrafo.

```html
<p>Este es un <i>texto en cursiva</i> dentro de un párrafo.</p>
```

Aquí, <i> es la etiqueta que hace que el texto "texto en cursiva" aparezca en cursiva.

###  Resumen

* HTML es la estructura básica de una página web, compuesta por elementos y etiquetas.

* Los elementos pueden ser anidados y algunos pueden ser autocerrados.
