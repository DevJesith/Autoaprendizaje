# Estructura de un Documento HTML

## 1. DOCTYPE
Indica al navegador que el documento es HTML.

## 2. Elemento HTML
Es el contenedor principal que incluye todo el contenido.

## 3. Elemento Head
Contiene información sobre el documento (no se muestra en la página).
- **Título**: Lo que aparece en la pestaña del navegador.
- **Meta etiquetas**: Información adicional como descripción y palabras clave.

## 4. Elemento Body
Contiene el contenido visible de la página (lo que los usuarios ven).

## Ejemplo
Imagina que estás creando una página para un restaurante llamado "Little Lemon". Aquí hay un ejemplo de cómo se vería el código HTML:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Little Lemon</title>
</head>
<body>
    <h1>Nuestro Menú</h1>
    <h2>Falafel</h2>
    <p>Chickpea, hierbas y especias.</p>
    <h2>Ensalada de Pasta</h2>
    <p>Lechuga, verduras y mozzarella.</p>
</body>
</html>
```

Explicación del Ejemplo

* Título: "Little Lemon" aparecerá en la pestaña del navegador.
* H1: "Nuestro Menú" es el encabezado principal.
* H2: "Falafel" y "Ensalada de Pasta" son subencabezados para los elementos del menú.
* P: Las descripciones de cada plato.
