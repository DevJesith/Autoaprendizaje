# Protocolos de Internet

## 1. Dynamic Host Configuration Protocol (DHCP)
- **Función**: Asigna direcciones IP a dispositivos en una red.
- **Ejemplo**: Cuando conectas tu laptop a una red Wi-Fi, el DHCP asigna automáticamente una dirección IP a tu laptop para que pueda comunicarse con otros dispositivos en la red.

## 2. Domain Name System Protocol (DNS)
- **Función**: Traduce nombres de dominio (como www.ejemplo.com) a direcciones IP.
- **Ejemplo**: Cuando escribes "www.google.com" en tu navegador, el DNS busca la dirección IP correspondiente para que tu computadora pueda conectarse al servidor de Google.

## 3. Internet Message Access Protocol (IMAP)
- **Función**: Permite a los dispositivos acceder y gestionar correos electrónicos en un servidor.
- **Ejemplo**: Si usas una aplicación de correo en tu teléfono, IMAP te permite ver tus correos electrónicos almacenados en el servidor sin descargarlos, lo que significa que puedes acceder a ellos desde diferentes dispositivos.

## 4. Simple Mail Transfer Protocol (SMTP)
- **Función**: Envía correos electrónicos desde un cliente a un servidor.
- **Ejemplo**: Cuando envías un correo electrónico desde tu aplicación de correo, SMTP se encarga de enviar ese correo al servidor de correo del destinatario.

## 5. File Transfer Protocol (FTP)
- **Función**: Transfiere archivos entre un cliente y un servidor.
- **Ejemplo**: Si necesitas subir archivos de tu computadora a un servidor web, usarías un cliente FTP para conectarte al servidor y transferir esos archivos.
