# Diferencias entre Páginas Web, Sitios Web y Aplicaciones Web

## Definiciones:

- **Página web**: 
  - Es un solo documento que se muestra en un navegador. 
  - Está compuesta por HTML, CSS y JavaScript.
  - **Ejemplo**: Una página de un artículo en un blog.

- **Sitio web**: 
  - Es una colección de páginas web que están interconectadas bajo un mismo nombre de dominio.
  - **Ejemplo**: Un sitio web de una universidad que tiene varias páginas, como la página de inicio, programas académicos, contacto, etc.

- **Aplicación web**: 
  - Es un tipo de sitio web que permite la interacción del usuario y tiene contenido dinámico.
  - **Ejemplo**: Un sitio de pedidos de comida en línea donde los usuarios pueden seleccionar elementos del menú, realizar pedidos y ver el estado de su pedido.

## Resumen de las diferencias:

- **Interactividad**: 
  - Las aplicaciones web son más interactivas que los sitios web.
  
- **Contenido dinámico**: 
  - Las aplicaciones web muestran contenido que cambia según la interacción del usuario, mientras que los sitios web suelen tener contenido estático.
