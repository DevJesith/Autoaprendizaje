# Resumen sobre Servidores y Servidores Web

## Resumen Simplificado:

- **Servidor**: Es una computadora que proporciona servicios a otras computadoras (clientes). Por ejemplo, un servidor puede almacenar un sitio web y enviarlo a tu navegador cuando lo solicitas.

- **Centro de datos**: Es un lugar donde se almacenan muchos servidores. Estos servidores están conectados a Internet y funcionan las 24 horas del día.

- **Hardware y Software**:
  - **Hardware**: Son las partes físicas del servidor (como el disco duro y la memoria).
  - **Software**: Es el código que se ejecuta en el hardware. Es más fácil de cambiar que el hardware.

- **Servidor web**: Un tipo específico de servidor que maneja solicitudes de páginas web. Cuando escribes una dirección web en tu navegador, el servidor web envía la información de esa página a tu dispositivo.

## Ejemplo:

Imagina que quieres ver un video en línea:

1. **Solicitud**: Abres tu navegador y escribes la dirección del video.
2. **Servidor web**: Tu solicitud llega a un servidor web que tiene el video almacenado.
3. **Respuesta**: El servidor web envía el video de vuelta a tu navegador, y puedes verlo.

Este proceso de enviar y recibir información se llama **ciclo de solicitud-respuesta**.
