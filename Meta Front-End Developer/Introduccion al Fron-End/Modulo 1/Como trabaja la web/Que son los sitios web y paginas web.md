# Sitios Web, Páginas Web y Aplicaciones Web

## Definiciones

- **Página Web**: 
  - Es un documento que se muestra en un navegador web. Puede contener texto, imágenes, videos y otros elementos multimedia.
  - Cada página web tiene su propia dirección URL (Uniform Resource Locator).

- **Sitio Web**: 
  - Es una colección de páginas web que están interconectadas y comparten un mismo dominio.
  - Un sitio web puede contener múltiples páginas web, cada una con su propio contenido y propósito.

- **Aplicación Web**: 
  - Es un tipo de software que se ejecuta en un navegador web y permite a los usuarios interactuar con él.
  - A diferencia de un sitio web estático, una aplicación web puede realizar funciones dinámicas, como enviar formularios, gestionar bases de datos y ofrecer interactividad en tiempo real.

## Ejemplo

Imagina que visitas tu enciclopedia favorita en línea:

1. **Página de inicio**: Esta es la primera página que ves al ingresar la URL del sitio. Contiene enlaces a diferentes artículos.
2. **Página de artículo**: Al hacer clic en un enlace, llegas a una nueva página que contiene un artículo específico. Esta es una **página web** dentro del **sitio web** de la enciclopedia.
3. **Aplicación Web**: Un ejemplo de aplicación web es un servicio de correo electrónico como Gmail. Permite a los usuarios enviar y recibir correos, gestionar contactos y realizar búsquedas, todo dentro del navegador.

## Conexiones

- Las páginas web dentro de un sitio web pueden enlazarse entre sí, permitiendo a los usuarios navegar fácilmente de un contenido a otro.
- Un sitio web puede también contener enlaces a otras páginas web que pertenecen a diferentes sitios.
- Las aplicaciones web utilizan tecnologías como HTML, CSS y JavaScript para ofrecer una experiencia interactiva y dinámica.

## Resumen

- **Página Web**: Documento individual en un navegador.
- **Sitio Web**: Conjunto de páginas web interconectadas bajo un mismo dominio.
- **Aplicación Web**: Software interactivo que se ejecuta en un navegador.
