# Cómo funciona un navegador web

## ¿Cómo funciona un navegador web?

1. **Solicitud del navegador**: Cuando abres un navegador y escribes una dirección web (URL), el navegador envía una solicitud a un servidor web. La URL incluye:
   - **Protocolo**: Generalmente HTTP o HTTPS.
   - **Nombre de dominio**: El nombre del sitio web (por ejemplo, www.ejemplo.com).
   - **Ruta del archivo**: La ubicación específica de la página que deseas ver.

2. **Comunicación con el servidor**: El navegador y el servidor se comunican utilizando el **Protocolo de Transferencia de Hipertexto (HTTP)**. El navegador envía la solicitud y espera una respuesta.

3. **Respuesta del servidor**: El servidor procesa la solicitud y envía de vuelta el contenido solicitado, que puede ser una página web, imágenes, etc.

4. **Visualización en el navegador**: Una vez que el navegador recibe la respuesta, renderiza (muestra) la página web en tu pantalla.

## Ejemplo:

Imagina que quieres buscar "restaurantes cerca de mí":

1. **Abres el navegador** y escribes "www.google.com" en la barra de direcciones.
2. **El navegador envía una solicitud** al servidor de Google.
3. **El servidor de Google responde** enviando la página de inicio de Google.
4. **Ves la página** en tu navegador.

Ahora, escribes "restaurantes cerca de mí" en la barra de búsqueda y presionas Enter:

1. **El navegador envía otra solicitud** al servidor de Google, esta vez con la búsqueda que realizaste.
2. **El servidor procesa la solicitud**, busca en su base de datos y encuentra información sobre restaurantes.
3. **El servidor envía de vuelta** una lista de restaurantes y un mapa.
4. **El navegador muestra** esta información en la pantalla.

Este proceso de solicitud y respuesta ocurre rápidamente, permitiéndote navegar por la web de manera eficiente.
