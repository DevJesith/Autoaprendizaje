## Contenido Estático vs. Contenido Dinámico

1.  Contenido Estático:

* Es el contenido que se entrega tal como está almacenado en el servidor.

* Ejemplos incluyen imágenes, videos y archivos HTML que no cambian.

* Ejemplo: Cuando visitas una página web que muestra una imagen de un producto, esa imagen es un contenido estático. El servidor simplemente envía el archivo de imagen al navegador sin cambios.

2. Contenido Dinámico:

* Se genera en el momento de la solicitud, a menudo basado en la interacción del usuario o en datos actuales.

* Ejemplo: Cuando inicias sesión en un sitio web, el servidor de aplicaciones verifica tu información y genera una página personalizada que muestra tu perfil, tus mensajes, etc. Este contenido se crea en tiempo real y puede cambiar cada vez que accedes.

## Servidores Web vs. Servidores de Aplicaciones

1. Servidor Web:

* Se encarga de enviar contenido estático al navegador del usuario.
Responde rápidamente a las solicitudes de archivos que no requieren procesamiento adicional.

* Ejemplo: Cuando haces clic en un enlace para ver un video, el servidor web envía el archivo de video directamente a tu navegador.

2. Servidor de Aplicaciones:

* Genera contenido dinámico y realiza procesos más complejos, como interactuar con bases de datos.

* Ejemplo: Cuando inicias sesión en un curso en línea, el servidor de aplicaciones verifica tu inscripción y genera la página que muestra el contenido específico para ti.

## Resumen

* Contenido Estático: No cambia, se entrega tal cual (ej. imágenes).

* Contenido Dinámico: Se genera en el momento, puede cambiar según la interacción del usuario (ej. perfil de usuario).
 
* Servidor Web: Entrega contenido estático rápidamente.

* Servidor de Aplicaciones: Genera contenido dinámico y maneja procesos complejos.


### Contenido Estático

* Definición: Es como un libro en una biblioteca. Siempre tiene la misma información y no cambia.

* Ejemplo: Una imagen de un gato en una página web. Cada vez que visitas esa página, ves la misma imagen. El servidor solo envía el archivo tal como está.

### Contenido Dinámico

* Definición: Es como una conversación. Cambia según lo que dices o 
preguntas.

* Ejemplo: Cuando inicias sesión en una red social, el contenido que ves (tus amigos, tus mensajes) se genera en ese momento. Cada vez que inicias sesión, puedes ver cosas diferentes porque depende de tus interacciones.

#### Resumen

* Contenido Estático: Siempre igual, como una imagen fija.

* Contenido Dinámico: Cambia según lo que haces, como una conversación en tiempo real.
