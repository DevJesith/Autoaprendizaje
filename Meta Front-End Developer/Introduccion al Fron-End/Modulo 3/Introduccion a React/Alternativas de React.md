React es una biblioteca y no un framework. Esto significa que, a menudo, utilizarás otras bibliotecas de JavaScript para crear tu aplicación. En esta lectura, conocerás brevemente algunas bibliotecas de JavaScript que se usan comúnmente con React.

# Lodash

https://lodash.com/

Como desarrollador, es común escribir mucha lógica en las aplicaciones. Por ejemplo, es posible que necesite ordenar una lista de elementos o redondear un número como  3,14  a  3. Lodash proporciona lógica común como estas como una biblioteca de utilidades para ahorrarle tiempo como desarrollador.

# Luxón

https://moment.github.io/luxon/#/

Como desarrollador, trabajarás con fechas y horas a menudo. Piensa en ver una lista de pedidos y cuándo se realizaron, o en mostrar un calendario para un evento. Las fechas y horas están en todas partes.

Luxon le ayuda a trabajar con fechas y horas al proporcionar funciones para manipularlas y mostrarlas. Por ejemplo, piense en cómo se formatean las fechas en diferentes países. En Estados Unidos, el formato es  Mes Día Año,  pero en Europa es  Día Mes Año . Esta es un área en la que Luxon puede ayudarle a mostrar la fecha en el formato local del usuario.

# Redux

https://redux.js.org/

Al crear una aplicación web, deberá realizar un seguimiento de su estado. Piense en cuando compra en línea. La aplicación web realiza un seguimiento de los artículos que se encuentran actualmente en su carrito de compras. Cuando elimina un artículo del carrito, la aplicación debe actualizar lo que se muestra en la pantalla. Aquí es donde entra en juego Redux. Le ayuda a administrar el estado de su aplicación e incluso tiene funciones avanzadas como deshacer y rehacer.

# Axios

https://axios-http.com/

Como desarrollador, te comunicarás con las API a través de HTTP con frecuencia. La biblioteca Axios ayuda a simplificar el envío de solicitudes HTTP y el procesamiento de la respuesta. También proporciona funciones avanzadas que te permiten cancelar solicitudes y cambiar los datos recibidos del servidor web antes de que tu aplicación los use.

# Jest

https://jestjs.io/

Como desarrollador profesional, es una buena práctica escribir pruebas automatizadas para su código. La biblioteca Jest le ayuda a hacer esto y funciona con muchas bibliotecas y marcos. También proporciona utilidades de generación de informes, como proporcionar información sobre qué parte de su código se prueba con las pruebas automatizadas.

## Conclusión

Si tiene curiosidad por aprender más sobre estas bibliotecas, sus sitios web cuentan con guías de configuración, tutoriales y documentación para comenzar. Hablaremos de estas bibliotecas más adelante.
