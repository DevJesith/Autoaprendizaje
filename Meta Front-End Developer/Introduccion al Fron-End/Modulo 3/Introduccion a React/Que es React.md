* React es una biblioteca de JavaScript utilizada para construir interfaces de usuario, especialmente en aplicaciones web y móviles.

* Se centra en el uso de componentes, que son piezas reutilizables de la interfaz de usuario.

* Permite a los desarrolladores escribir menos código, lo que facilita el mantenimiento y las pruebas.

## Ejemplo de Componentes en React:

1. Componente de Icono de Usuario:

* Imagina que tienes una aplicación donde se muestra la foto de perfil de un usuario en varias partes: en la barra de navegación, en los resultados de búsqueda y en las notificaciones.

* En lugar de escribir el código para mostrar la foto en cada lugar, puedes crear un componente de icono de usuario. Este componente se encarga de mostrar la foto de perfil y se puede reutilizar en todas las partes de la aplicación.

2. Componente de Reproductor de Video:

* Si deseas agregar un reproductor de video a tu sitio web, puedes usar una biblioteca de componentes de React que ya tenga un componente de reproductor de video preconstruido.

* Esto te ahorra tiempo y esfuerzo, ya que no necesitas construir el reproductor desde cero.
