1. HTML (HyperText Markup Language)

HTML es el lenguaje de marcado utilizado para crear la estructura de una página web. Se compone de elementos que definen diferentes partes del contenido.

```html
<h1>Bienvenido a mi Restaurante</h1>
<p>Ofrecemos los mejores platos de la ciudad.</p>
```

<h1> es un encabezado principal.
<p> es un párrafo.

2. CSS (Cascading Style Sheets)

CSS se utiliza para controlar la apariencia de los elementos HTML. Permite aplicar estilos como colores, fuentes y márgenes.

Ejemplo:

```css
h1 {
    color: blue;
    font-size: 24px;
}
```

* Este código cambiará el color del texto del encabezado a azul y su tamaño a 24 píxeles.

3. Bootstrap

Bootstrap es un marco de trabajo (framework) que facilita la creación de sitios web responsivos. Proporciona clases predefinidas que puedes usar para diseñar rápidamente.

Ejemplo:

```html
<div class="container">
    <div class="row">
        <div class="col">
            <h2>Menú</h2>
            <p>Falafel</p>
        </div>
        <div class="col">
            <h2>Precios</h2>
            <p>$12</p>
        </div>
    </div>
</div>
```

* Aquí, container, row, y col son clases de Bootstrap que ayudan a organizar el contenido en columnas.

4. Creación de una Página Web Simple

Combina HTML y CSS con Bootstrap para crear una página web básica. Por ejemplo, una página de menú de un restaurante.

* Estructura:

    * Un encabezado con el nombre del restaurante.
    * Dos columnas: una para el menú y otra para los precios.
