Bootstrap components son elementos predefinidos que facilitan la creación de interfaces de usuario en sitios web. Estos componentes incluyen estilos y funcionalidades que permiten a los desarrolladores construir páginas web de manera más rápida y eficiente.

## Ejemplos de componentes de Bootstrap:

1. Alertas:

* Se utilizan para mostrar mensajes importantes a los usuarios.

* Ejemplo: Para informar a los clientes sobre un nuevo plato en el menú, puedes usar una alerta de la siguiente manera:
```html
<div class="alert alert-info" role="alert">
  ¡Prueba nuestro nuevo plato de calamares fritos!
</div>
```
2. Tarjetas (Cards):

* Son contenedores flexibles que pueden incluir texto, imágenes y enlaces.

* Ejemplo: Para mostrar un plato en el menú, puedes usar una tarjeta así:

```html
<div class="card" style="width: 18rem;">
  <img src="calamari.jpeg" class="card-img-top" alt="Calamares Fritos">
  <div class="card-body">
    <h5 class="card-title">Calamares Fritos</h5>
    <p class="card-text">Deliciosos calamares fritos servidos con salsa.</p>
    <a href="#" class="btn btn-primary">Ordenar</a>
  </div>
</div>
```

## Resumen:

* Bootstrap proporciona componentes como alertas y tarjetas que ayudan a mejorar la apariencia y funcionalidad de un sitio web.

* Estos componentes son fáciles de implementar y personalizar, lo que permite a los desarrolladores centrarse en el contenido y la experiencia del usuario.
