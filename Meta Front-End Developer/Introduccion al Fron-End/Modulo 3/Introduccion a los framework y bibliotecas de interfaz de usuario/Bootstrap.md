# Bootstrap

Bootstrap se describe a menudo como una forma de "crear sitios rápidos y con capacidad de respuesta" y es un "kit de herramientas frontend repleto de funciones, potente y extensible". 

Algunas personas se refieren a él como un marco de "front-end", y otras intentan ser más específicas al referirse a él como un "marco CSS" o una "biblioteca CSS". 

Entonces, ¿qué es Bootstrap?

En pocas palabras, Bootstrap es una biblioteca de código CSS y JavaScript que puedes combinar para crear rápidamente sitios web visualmente atractivos.

El desarrollo web moderno se basa en  componentes . Pequeños fragmentos de código reutilizables que permiten crear sitios web rápidamente. Bootstrap incluye varios componentes para una construcción muy rápida de varios componentes o partes de componentes. 

Otro aspecto importante del desarrollo moderno son  las cuadrículas responsivas  , que permiten que las páginas web adapten su diseño y contenido según el dispositivo en el que se visualicen. Bootstrap viene con un conjunto de reglas CSS predefinidas para crear una cuadrícula responsiva.

Bootstrap es muy popular entre los desarrolladores porque ahorra tiempo de desarrollo y proporciona una forma para que los desarrolladores creen prototipos y sitios web visualmente atractivos.

Bootstrap ahorra mucho tiempo porque todo el código CSS que le da estilo a su cuadrícula y a sus componentes prediseñados ya está escrito. En lugar de tener que tener un alto nivel de experiencia en varios conceptos CSS, puedes usar las clases CSS de Bootstrap existentes para crear sitios web de aspecto atractivo. Esto es indispensable cuando necesitas iterar rápidamente en los diseños de sitios web. 

Una vez que sepas cómo funciona Bootstrap, tendrás el conocimiento suficiente para modificar su estilo y se abrirá ante ti un mundo completamente nuevo de desarrollo.

Como Bootstrap es tan popular, comprender cómo trabajar con él es un requisito previo en muchas empresas de desarrollo web. Además, puede estar seguro de que tanto usted como los miembros de su equipo tienen un sistema de diseño común y no tiene que perder tiempo decidiendo cómo crear uno. Tiene la libertad de pasar de un equipo a otro, de un proyecto a otro, incluso de una empresa a otra, y no necesita volver a aprender "su forma de hacer las cosas".

Todos estos puntos hacen que invertir tiempo en aprender Bootstrap sea una excelente manera de mejorar tus habilidades de desarrollo web. En esta lección, conocerás los conceptos básicos de Bootstrap y aprenderás a crear páginas web con él.
