# Interactividad de JavaScript

El propósito de esta lectura es presentarle una explicación sencilla sobre la manipulación de páginas web y algunos ejemplos de ella.

¿Sabías que el propósito inicial de JavaScript era  proporcionar interactividad en el navegador?

En otras palabras, era el "conjunto de controles" que permitiría a los desarrolladores web controlar el comportamiento de las páginas web e incluso los navegadores en los que funcionaban dichas páginas.

Esto sigue siendo así hoy en día.

A medida que el ecosistema web se desarrolló y el mundo se volvió cada vez más digitalizado, también lo hicieron las innumerables formas en que uno puede usar JavaScript como desarrollador web para manipular sitios web.

Inicialmente, a finales de la década de 1990, existía JavaScript simple que debía modificarse para adaptarlo a cada navegador.

Luego, a mediados de la década de 2000, apareció la biblioteca jQuery, con la idea de escribir menos código, pero hacer más con él. "Niveló las reglas del juego", ya que permitió a los desarrolladores utilizar una única base de código para varios navegadores.

Esta tendencia continuó y aparecieron muchos otros marcos como React, Vue, Angular, D3 y más.

Junto con npm y Node.js, el ecosistema de JavaScript no se está desacelerando.

Aunque se ha avanzado mucho, a veces es bueno volver a lo básico. JavaScript sigue siendo el rey cuando se trata de hacer que nuestros sitios web sean interactivos.

Aunque CSS se ha desarrollado significativamente a lo largo de los años, todavía es JavaScript el que permite a los usuarios:

* Obtenga su geolocalización,

* Interactuar con mapas,

* Juega juegos en el navegador,

* Manejar todo tipo de eventos activados por el usuario, independientemente del dispositivo,

* Verificar la entrada del formulario antes de enviarlo al backend de una aplicación web.

* ¡y mucho más!

Hay muchísimas maneras en las que JavaScript le permite crear experiencias ricas e interactivas en la web.
