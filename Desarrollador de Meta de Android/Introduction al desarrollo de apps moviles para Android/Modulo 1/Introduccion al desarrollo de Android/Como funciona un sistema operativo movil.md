# ¿Cómo funciona un sistema operativo móvil?

## Definición
Un **sistema operativo móvil (OS)** es el software fundamental que coordina las comunicaciones entre el hardware y las aplicaciones de un dispositivo móvil.

## Funciones Principales
- **Gestión de Recursos**: Permite que las aplicaciones accedan a recursos del dispositivo como el procesador, memoria, wifi y Bluetooth.
- **Interfaz de Usuario**: Administra la experiencia del usuario a través de íconos de aplicaciones y elementos de la interfaz.
- **Interacción Multitáctil**: Facilita la interacción del usuario mediante gestos táctiles como deslizar, tocar y tirar.

## Sistemas Operativos Populares
1. **Android**:
   - Lanzado en 2008.
   - Basado en el kernel de Linux.
   - Utilizado en una variedad de dispositivos como teléfonos, tabletas y relojes inteligentes.

2. **iOS**:
   - Propiedad de Apple.
   - Utilizado en iPhone, iPad y otros dispositivos móviles.
   - Introduce herramientas para desarrolladores como el kit de desarrollo de software (SDK).

## Conclusión
Los sistemas operativos móviles son esenciales para el funcionamiento de dispositivos portátiles, permitiendo la ejecución de aplicaciones y la interacción del usuario de manera eficiente.
