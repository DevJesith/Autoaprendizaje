* Pruebas Unitarias:

    * Descripción: Se centran en probar componentes individuales del código de forma aislada.

    * Ejemplo: Si tienes una función en Python que suma dos números, escribirías una prueba unitaria para verificar que la función devuelve el resultado correcto para diferentes pares de números.


* Pruebas de Integración:

    * Descripción: Combinan múltiples componentes y prueban cómo interactúan entre sí.

    * Ejemplo: Si tienes una función que obtiene datos de una base de datos y otra que los muestra en una página web, una prueba de integración verificaría que los datos se transfieren correctamente entre ambas funciones.

* Pruebas del Sistema:

    * Descripción: Evalúan el sistema completo para asegurarse de que cumple con los requisitos establecidos.

    * Ejemplo: Probar una aplicación web completa para asegurarse de que todas las funcionalidades, como el inicio de sesión, la búsqueda y la compra, funcionan correctamente en conjunto.

* Pruebas de Aceptación:

    * Descripción: Se realizan para determinar si el sistema es aceptable para el usuario final.

    * Ejemplo: Un grupo de usuarios seleccionados prueba la aplicación y proporciona retroalimentación sobre su experiencia, asegurándose de que cumple con sus expectativas.
