* Definición: Las pruebas de software son un proceso de evaluación y verificación de aplicaciones y productos de software para asegurar su rendimiento, corrección y completitud.

* Objetivo: Identificar errores, defectos y requisitos faltantes en el software.

* Evolución: Antes, las pruebas se realizaban en etapas tardías; ahora, se integran desde las primeras fases del desarrollo.

* Ciclo de Pruebas: Incluye planificación, preparación, ejecución y reporte de resultados.

- Ejemplos:

1. Pruebas de un sitio web: Imagina que has creado un sitio web que recibe 100 visitantes diarios. Si un artículo se vuelve viral y atrae a un millón de visitantes, es crucial que el sitio esté bien probado para evitar que se caiga.

2. Validación de formularios: Al llenar un formulario en línea, si ingresas letras en un campo que solo acepta números (como el número de tarjeta de crédito), el sistema debe alertarte sobre el error. Esto es un ejemplo de validación de datos, esencial en áreas como la banca.
