Manejo de Excepciones: Se utiliza para gestionar errores que pueden ocurrir durante la ejecución del código.

Estructura: Se emplean las declaraciones try y except para intentar ejecutar un bloque de código y manejar cualquier excepción que ocurra.

Ejemplo: Se define una función divide_by(a, b) que intenta dividir a entre b. Si b es 0, se genera un error de división por cero.
Mensajes de Error: Puedes personalizar los mensajes de error para que sean más amigables para el usuario.

Captura de Excepciones: Puedes capturar información sobre la excepción usando as e para obtener detalles específicos.
Múltiples Excepciones: Puedes encadenar múltiples bloques except para manejar diferentes tipos de excepciones.
