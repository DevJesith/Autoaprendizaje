Creación de archivos : utilice la openfunción con el modo de escritura ( w) para crear un nuevo archivo.

Escritura de contenido : utilice la writefunción para líneas individuales o writelinesmúltiples, asegurándose de incluir caracteres de nueva línea ( \n) para dar formato.

Agregar a archivos : cambie el modo a agregar ( a) para agregar contenido sin sobrescribir los datos existentes.

Manejo de errores : Implemente declaraciones tryy exceptmétodos para administrar excepciones, como errores de archivo no encontrado.
