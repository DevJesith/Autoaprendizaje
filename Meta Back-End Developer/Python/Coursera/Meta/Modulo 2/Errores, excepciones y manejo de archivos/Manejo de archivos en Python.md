Manejo de Archivos: Es esencial para trabajar con grandes cantidades de datos. Incluye abrir, leer y escribir archivos.

Funciones Principales:

open(): Se utiliza para abrir archivos. Acepta dos argumentos: el nombre del archivo y el modo (lectura, escritura, etc.).

close(): Cierra la conexión del archivo abierto.
Modos de Apertura:

r: Leer un archivo en formato de texto.
rb: Leer un archivo en formato binario.
w: Escribir en un archivo (sobrescribe el existente).
a: Añadir datos a un archivo existente.
r+: Leer y escribir en un archivo.
with open(): Una forma más segura de manejar archivos que cierra automáticamente el archivo al finalizar.

Formatos de Archivo:
Texto: Legible por humanos.
Binario: Más compacto y eficiente, pero no legible por humanos.
