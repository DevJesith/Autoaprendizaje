# Resumen: Construcción de Páginas Web y Ciclo de Solicitud/Respuesta

## Estructura de una Aplicación Web
- **Componentes Clave**:
  - **Navegador**: Software que se ejecuta en el dispositivo del usuario (ej. Chrome, Firefox).
  - **Servidor**: Donde se aloja la aplicación web.
  - **Servidor de Base de Datos**: Almacena y gestiona los datos.

## Tecnologías Involucradas
- **HTML**: Lenguaje de marcado que estructura el contenido.
- **CSS**: Se utiliza para estilizar el contenido (fuentes, colores).
- **JavaScript**: Permite la interacción dinámica con el contenido.
- **PHP**: Lenguaje del lado del servidor para procesar solicitudes.
- **SQL**: Lenguaje para gestionar bases de datos.

## Ciclo de Solicitud/Respuesta
1. **Solicitud**: El usuario ingresa una URL en el navegador.
2. **GET Request**: El navegador envía una solicitud al servidor.
3. **Respuesta**: El servidor procesa la solicitud y devuelve el contenido en formato HTML.
4. **Renderizado**: El navegador interpreta el HTML y muestra la página al usuario.

## Protocolo HTTP
- **Definición**: Protocolo de transferencia de hipertexto, fundamental para la comunicación en la web.
- **Estructura de URL**:
  - `http://` - Protocolo
  - `servidor` - Dirección del servidor
  - `documento` - Archivo específico solicitado

## Navegación Hipertextual
- **Enlaces**: Utilizan etiquetas `<a>` con atributos `href` para navegar entre páginas.
- **Interacción**: Al hacer clic en un enlace, se genera una nueva solicitud GET.

## Estándares de Internet
- **IETF**: Grupo que desarrolla estándares abiertos para la interoperabilidad en la web.
- **RFC**: Documentos que describen los estándares y protocolos.

## Conclusión
Entender la estructura y el funcionamiento de las aplicaciones web es esencial para desarrollar habilidades en programación web y crear aplicaciones efectivas.
