# Resumen de HTML

## Estructura Básica de un Documento HTML
- **HTML Tag**: Define el inicio y el final de un documento HTML.
- **DOCTYPE**: Indica la versión de HTML utilizada.
- **Head**: Contiene metadatos que no se muestran en la página, como enlaces a CSS.
- **Body**: Contiene el contenido visible de la página.

## Archivos Especiales
- **index.html**: Archivo predeterminado que se carga al acceder a un directorio en un servidor web.

## Etiquetas HTML
- **Etiquetas**: Se utilizan para marcar el contenido. Tienen una etiqueta de inicio y una de cierre (ej. `<b>` para negrita).
- **Atributos**: Proporcionan información adicional sobre las etiquetas (ej. `src` en la etiqueta de imagen).

## Entidades HTML
- Se utilizan para representar caracteres especiales (ej. `&lt;` para `<`).

## Comentarios HTML
- Se utilizan para agregar notas en el código que no se muestran en la página (ej. `<!-- Comentario -->`).

## Enlaces
- **Anchor Tag (`<a>`)**: Se utiliza para crear enlaces a otras páginas. Tiene un atributo `href` que define la URL de destino.

## Imágenes
- **Image Tag (`<img>`)**: Se utiliza para insertar imágenes en la página. Debe incluir el atributo `src`.

## Listas
- **Listas No Ordenadas (`<ul>`)**: Se utilizan para crear listas con viñetas.
- **Listas Ordenadas (`<ol>`)**: Se utilizan para crear listas numeradas.

## Tablas
- **Table Tag (`<table>`)**: Se utiliza para crear tablas. Contiene filas (`<tr>`) y celdas (`<td>`).

## Visualización del Código
- Puedes ver el código fuente de una página web haciendo clic derecho y seleccionando "Ver fuente" o "Inspeccionar elemento".

## Conclusión
HTML es un lenguaje de marcado simple y declarativo que permite estructurar contenido en la web. A medida que avanzas, aprenderás a combinar HTML con CSS para mejorar el diseño de tus páginas.
