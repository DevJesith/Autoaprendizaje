# Resumen de HTML

## Introducción a HTML
- **HTML (Hypertext Markup Language)** es el lenguaje de marcado utilizado para crear páginas web.
- HTML define la estructura y el contenido de un documento web.

## Estructura de un Documento HTML
- Un documento HTML está compuesto por **etiquetas** que indican cómo se debe mostrar el contenido.
- Ejemplos de etiquetas:
  - `<p>`: Inicia un párrafo.
  - `<strong>`: Inicia texto en negrita.

## Funcionamiento de HTML
- HTML se utiliza en conjunto con **HTTP** (Hypertext Transfer Protocol) para recuperar documentos de un servidor web.
- El navegador interpreta el HTML y lo convierte en una representación visual en la pantalla.

## Historia de HTML
- HTML fue creado en los años 90 por **Tim Berners-Lee** y **Robert Cailliau**.
- Ha evolucionado a través de varias versiones, siendo **HTML5** la más reciente y utilizada hoy en día.

## Importancia de HTML
- HTML es fundamental para la creación de aplicaciones web y es la base sobre la cual se construyen otros lenguajes y tecnologías web, como CSS y JavaScript.

## Conclusión
- HTML es un lenguaje accesible y esencial para cualquier persona interesada en el desarrollo web.
