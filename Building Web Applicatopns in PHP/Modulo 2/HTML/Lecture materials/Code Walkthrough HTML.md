# Resumen del Code Walkthrough: HTML

## Introducción

En este recorrido de código, se explora cómo interactuar con el código HTML y cómo se representa en el navegador a través del Modelo de Objetos del Documento (DOM).

### Conceptos Clave:

- **Código Fuente vs. DOM**:
  - El **código fuente** es el texto original que se encuentra en el archivo HTML.
  - El **DOM** es la representación estructurada que el navegador crea a partir del código fuente, permitiendo la manipulación dinámica de la página.

- **Inspección de Elementos**:
  - Utilizar herramientas de desarrollo del navegador para inspeccionar elementos y ver cómo se estructuran en el DOM.

- **Etiquetas HTML**:
  - Se revisan etiquetas como `<p>`, `<strong>`, `<a>`, y listas desordenadas `<ul>`, y cómo se utilizan para estructurar el contenido.

- **Enlaces**:
  - Se discute la diferencia entre enlaces relativos y absolutos, y cómo los navegadores manejan estos enlaces.

- **Espacios en Blanco y Formato**:
  - Se menciona que los espacios en blanco en el código HTML no afectan la visualización en el navegador.

- **Caracteres Especiales**:
  - Se explican los caracteres especiales en HTML y cómo deben ser representados (por ejemplo, `&lt;` para `<`).

- **Errores Comunes**:
  - Se destacan errores comunes en HTML, como etiquetas no cerradas y el uso incorrecto de mayúsculas en las etiquetas.
